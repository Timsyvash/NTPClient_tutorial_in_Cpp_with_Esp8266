# 🕒 NTP Client Wi-Fi Clock (ESP8266 + NeoPixel Matrix)

Проект цифрового годинника реального часу на базі мікроконтролера **ESP8266 (Wemos D1 Mini)** та світлодіодної адресної матриці **WS2812B (16x16)**. 

Пристрій підключається до домашньої мережі Wi-Fi, запитує точний час через протокол **NTP (Network Time Protocol)** і відображає його на матриці. Проект реалізований у середовищі **VS Code + PlatformIO** мовою C++.

---

## 📌 Особливості проекту

- **🌐 Автоматична синхронізація часу**: Не потрібні фізичні модулі RTC (наприклад, DS3231) — точний час завантажується з серверів Інтернету.
- **⚡ Неблокуючий код (Non-blocking)**: Опитування часу та оновлення світлодіодної матриці виконуються через інтервали `millis()`, що дозволяє легко додавати анімації та фонові ефекти.
- **🧩 Рендеринг шрифтів**: Виведення компактних цифр на матрицю 16×16 з урахуванням зигзагоподібної схеми підключення пікселів.
- **🔌 Сучасне залізо**: Повна сумісність із версією Wemos D1 Mini (USB Type-C).

## 🛠 Апаратні вимоги

| Компонент | Кількість | Опис / Примітка |
| :--- | :---: | :--- |
| **Wemos D1 Mini** | 1 | Плата на базе ESP8266 (Micro-USB або Type-C) |
| **LED Матриця WS2812B** | 1 | Розмір 16×16 (256 світлодіодів, Zigzag) |
| **Блок живлення** | 1 | 5V DC, від **2A** |
| **Конденсатор** *(рекомендовано)* | 1 | 1000uF 6.3V (на лінію 5V) |

## 🔌 Схема підключення (Pinout)

> **Увага:** Логіка ESP8266 працює на напрузі 3.3V, але пін `5V` (або `VIN`) видає напругу живлення від USB, якої вистачає для роботи матриці на помірній яскравості. Для стабільної роботи від 256 світлодіодів рекомендується зовнішній блок живлення 5V.

```text
  [ Зовнішній Блок Живлення 5V ] ─────┬─────────────► VCC (Матриця WS2812B)
                                      │
  [ Wemos D1 Mini GND ] ──────────────┼─────────────► GND (Матриця WS2812B)
                                      │
  [ Wemos D1 Mini Pin D4 (GPIO2) ] ──[ 330Ω ]───────► DIN (Матриця WS2812B)
                                     ═══ 1000uF
                                      │
                                     GND
